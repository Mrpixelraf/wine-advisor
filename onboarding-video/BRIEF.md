# Sommé 颂美 — Onboarding Video Brief

## 背景
Sommé 颂美是一款 AI 私人侍酒师 Web App，即将公测。需要一个新用户引导动画视频，用 Remotion 制作。

## 目标
用 Remotion 制作一个 30-45 秒的引导动画视频（1080x1920 竖屏，适合手机），展示所有核心功能。

## 视频内容结构（必须全部覆盖）

### Scene 1: 欢迎 (0-5s)
- Logo + 品牌名 "Sommé 颂美"
- 标语 "好酒不必懂，懂你就够了"
- 优雅的淡入动画

### Scene 2: 四大场景介绍 (5-20s)
展示四大核心功能卡片（用截图 `01-home.jpg` 为参考）：
1. 🍽️ **在餐厅** — 拍菜单/酒单，AI 秒出搭配推荐
2. 🛒 **选购葡萄酒** — 按场景、口味、预算智能选酒
3. 🔍 **认识一瓶酒** — 拍照识别酒标，了解酒款故事
4. ✍️ **品酒记录** — AI 引导品鉴（外观→香气→口感→余味）
每个卡片逐个飞入/缩放动画，下方展示"或直接提问"的快捷标签

### Scene 3: 拍照识酒 + 智能分流 (20-30s)
- 展示拍照按钮（底部相机图标）
- 模拟拍酒标后 AI 识别酒款信息
- 展示"想买"vs"在喝"智能分流选择
  - 想买模式 → 评分(X/100) + 风味描述 + 同价位推荐 + 参考价格
  - 在喝模式 → 专业 Tasting Notes（外观/香气/口感/余味）
- 参考 `02-restaurant.jpg` 对话界面

### Scene 4: AI 引导品鉴流程 (30-38s)
- 展示品酒记录的完整流程：
  - 四步品鉴：外观(颜色/清澈度) → 香气(果香/花香/橡木) → 口感(酸度/单宁/酒体) → 余味(长度/描述词)
  - 三个级别：入门/进阶/专家（适应不同用户）
  - 品鉴打分滑块（0-100分）
  - 风味标签选择（果味/花香/辛香/泥土/橡木等）
- 完成后自动存入酒窖

### Scene 5: 我的酒窖 (38-44s)
- 展示酒窖界面（参考 `03-cellar.jpg`）
- "品过的酒"、"我的藏酒"、"想买清单" 三个 tab 动画切换
- 每瓶酒的记录：评分、品鉴笔记、风味标签、图片
- 导出/分享功能

### Scene 6: 语言切换 (44-48s)
- 高亮左上角 EN/中 按钮
- 展示中英切换效果（参考 `04-en-home.jpg`）
- 文字提示："支持中英双语，AI 回复也会跟着切换"

### Scene 7: 结尾 CTA (48-55s)
- "开始你的品酒之旅"
- Logo + 品牌标语 "好酒不必懂，懂你就够了"
- 网站地址
- 渐隐结束

## 设计风格
- **配色**: 酒红色(#722F37) + 奶白色(#FDF8F0) + 金色点缀(#C9A96E)
- **字体**: Cormorant Garamond (标题) + Noto Serif SC (中文) + Inter (正文)
- **动画**: 优雅、流畅，不要太花哨。淡入淡出 + 轻微缩放 + 滑入
- **整体感觉**: 高端侍酒师氛围，温暖但不浮夸
