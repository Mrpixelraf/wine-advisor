## 5. 发现的问题列表

### 🟡 中等问题

1. **🟡 主色与品牌规范不完全一致**
   - 品牌规范：主色 `#8B2252`，背景 `#FAF7F2`
   - 实际使用：`--wine-deep: #722F37`，`--wine-cream: #FAF5F0`
   - **影响**：视觉效果仍然协调，但与官方品牌手册不一致
   - **建议**：如果 `#722F37` 是设计师调整后的最终色值，需更新品牌手册；否则需调整 CSS

2. **🟡 Cormorant Garamond 字体未加载**
   - 品牌标题（`h1`、酒窖标题、评分数字）使用 `'Cormorant Garamond'`
   - 但 Google Fonts 导入链接中**未包含该字体**
   - 实际渲染会 fallback 到 `'Noto Serif SC', serif`
   - **建议**：在 `layout.tsx` 的 Google Fonts URL 中添加 `family=Cormorant+Garamond:wght@400;500;600;700`

3. **🟡 无自定义 Favicon**
   - `app/public/` 中无 favicon 文件
   - `app/src/app/favicon.ico` 存在但可能是 Next.js 默认的
   - 品牌 App 应有定制的酒杯/酒瓶 icon
   - **建议**：设计酒红色酒杯图标作为 favicon + apple-touch-icon

4. **🟡 对话历史无分组管理**
   - 当前只有「清除全部」选项
   - 没有多轮对话分组/历史列表
   - 关闭浏览器重开后只能看到一个连续的对话
   - **建议**：v1.0 可考虑添加对话列表侧栏

### 🟢 轻微问题

5. **🟢 深色模式未完全实现**
   - `layout.tsx` 中有深色模式检测代码 (`localStorage.getItem('somme-theme')`)
   - 但 CSS 中无 `.dark` 类相关样式定义
   - **建议**：暂时移除深色模式检测代码，或完善深色模式样式

6. **🟢 未使用的 Google Fonts 字体**
   - `JetBrains Mono` 加载了但代码中未直接使用
   - `DM Serif Display` 加载了但代码中未使用
   - **影响**：轻微的页面加载性能损失
   - **建议**：清理未使用的字体导入

7. **🟢 public 目录包含 Next.js 默认 SVG**
   - `file.svg`、`globe.svg`、`next.svg`、`vercel.svg`、`window.svg` 是脚手架残留
   - **建议**：清理不需要的文件

8. **🟢 Anthropic SDK 未使用**
   - `package.json` 依赖 `@anthropic-ai/sdk`，但实际 API 使用 Gemini
   - **建议**：移除未使用的依赖，减小 `node_modules`

9. **🟢 `@keyframes cellarSlideIn` 重复定义**
   - `globals.css` 中 `cellarSlideIn` 动画定义了两次（第一次 `translateY`，第二次 `translateX`）
   - 后者会覆盖前者
   - **建议**：删除重复定义，保留期望的动画方向

10. **🟢 `line-clamp-2` 工具类重复定义**
    - `globals.css` 中 `.line-clamp-2` 定义了两次
    - **建议**：删除重复
