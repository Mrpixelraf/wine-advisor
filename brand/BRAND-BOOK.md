# 1. 品牌研究与竞品分析

## 1.1 行业格局

葡萄酒科技（Wine Tech）领域正处于高速成长期。AI 技术的成熟为传统品酒文化注入了全新可能——从图像识别到个性化推荐，从自然语言对话到品鉴教育，技术正在重塑人与酒的关系。

## 1.2 竞品深度分析

### 🟣 Vivino — 社区驱动的酒类电商

| 维度 | 分析 |
|------|------|
| **定位** | "Buy the Right Wine" — 以社区评分和购买为核心 |
| **品牌调性** | 亲民、数据驱动、实用主义 |
| **视觉风格** | 深紫/酒红主色，现代无衬线字体，扁平化图标 |
| **核心体验** | 扫码识酒 → 查看评分 → 购买 |
| **优势** | 全球最大酒类 UGC 数据库，1500万+评分 |
| **不足** | 缺乏深度品鉴指导；社区噪音大；商业化导向过重 |
| **品牌启示** | ✅ 扫描识别是刚需入口 ❌ 纯评分导向缺乏灵魂 |

### 🔴 Wine Spectator — 权威评分殿堂

| 维度 | 分析 |
|------|------|
| **定位** | 全球最权威的葡萄酒评分与报道杂志 |
| **品牌调性** | 权威、精英、传统 |
| **视觉风格** | 经典衬线字体，黑+酒红配色，杂志级排版 |
| **核心体验** | 专家评分 → 深度报道 → 年度榜单 |
| **优势** | 百分制评分系统全球公认；专家团队公信力强 |
| **不足** | 数字化转型缓慢；付费墙阻碍触达；缺乏互动性 |
| **品牌启示** | ✅ 权威感的建立方式值得学习 ❌ 过于精英化，距离感过强 |

### 🟠 Decanter — 英伦品鉴美学

| 维度 | 分析 |
|------|------|
| **定位** | "Wine Reviews & News" — 英式优雅的品酒文化传播者 |
| **品牌调性** | 优雅、知性、学院派 |
| **视觉风格** | 温暖色调，衬线+无衬线混排，高品质摄影 |
| **核心体验** | 深度文章 → 大师评分 → 品酒教育 |
| **优势** | Decanter World Wine Awards 全球影响力；内容品质极高 |
| **不足** | 数字产品体验一般；中国市场渗透有限 |
| **品牌启示** | ✅ 内容驱动品牌的典范 ✅ 英伦优雅调性契合我们定位 |

### 🟢 Coravin — 科技奢侈品

| 维度 | 分析 |
|------|------|
| **定位** | 重新定义"一杯"葡萄酒的科技硬件品牌 |
| **品牌调性** | 极简、奢华、创新 |
| **视觉风格** | 黑+金配色，大量留白，产品hero shot |
| **核心体验** | 不开瓶取酒 → 保鲜 → 按杯享用 |

| **不足** | 价格门槛高；使用场景有限 |

### 🔵 CellarTracker — 极客的酒窖

| 维度 | 分析 |
|------|------|
| **定位** | 全球最大的个人酒窖管理平台 |
| **品牌调性** | 功能至上、社区驱动、工具化 |
| **视觉风格** | 朴素、数据密集型界面 |

| **品牌启示** | ✅ 酒窖管理是真实需求 ❌ 纯工具化缺乏情感连接 |

## 1.3 市场机会总结

| 维度 | 现有玩家 | 我们的差异化 |
|------|----------|------------|
| 识别 | Vivino（扫码查评分） | AI 对话式识别+深度解读 |

**核心洞察：** 市场上没有一个产品能做到"懂酒+懂你+会聊天"。我们的机会在于成为**第一个有温度的 AI 侍酒师**。

# 2. 品牌定位

## 2.1 品牌使命 (Mission)

> **让每个人都拥有一位世界级私人侍酒师。**
>
> Giving everyone a world-class personal sommelier.

我们相信，好酒不应该只属于少数人。通过 AI 技术，我们将数百年的侍酒师智慧，化为每个人口袋里的品酒伙伴。

## 2.2 品牌愿景 (Vision)

> **成为全球最受信赖的 AI 品酒伙伴，让每一杯酒都喝得明白、喝得快乐。**
>
> To be the world's most trusted AI wine companion — making every glass understood and enjoyed.

## 2.3 品牌价值观 (Values)

### 🍇 **博学 · Knowledgeable**
如同顶级侍酒师，我们对葡萄酒的知识广博而精深——从风土到年份，从品种到配餐，永远给出值得信赖的建议。

### 🤝 **亲和 · Approachable**
我们拒绝葡萄酒世界的装腔作势。无论你是初次品酒还是资深藏家，我们都用温暖、不带评判的方式与你交流。

### ✨ **优雅 · Elegant**
我们相信细节之美。从一个配色到一段文案，从一次推荐到一个动画，每一个触点都应体现品位。

### 🔬 **求真 · Authentic**
我们不为了推销而推荐。真实的品鉴、诚实的评价、透明的信息——这是我们与用户建立信任的基石。

### 🌱 **成长 · Growing**
每一杯酒都是一次探索。我们陪伴用户在品酒之路上持续成长，从好奇到热爱，从入门到精通。

# 4. 视觉识别系统

## 4.1 设计理念

### 核心概念：**「醇 · 雅 · 智」**

- **醇 (Rich)** — 如同好酒，视觉上追求层次感、深度和温暖
- **雅 (Elegant)** — 继承葡萄酒文化的典雅，现代而不浮华
- **智 (Intelligent)** — 体现 AI 科技的精准与未来感

### 设计原则

1. **少即是多** — 奢华不在于堆砌，而在于克制
2. **温暖的权威** — 专业但不冰冷，精致但不疏离
3. **动静皆宜** — 静态时优雅如杂志，动态时流畅如美酒
4. **中西融合** — 西方葡萄酒美学与东方含蓄雅韵的结合

---

## 4.2 Logo 概念设计

### 方向 A：**「侍酒之环」 The Sommelier's Ring**

**概念描述：**

以抽象的酒杯剖面为基础形态，杯身曲线与字母 "S"（Somme 的首字母）融为一体。杯口形成一个优雅的圆环（象征酒杯残留的酒渍光环 — 品酒文化中的经典意象），环内带有极细的 AI 电路纹理，暗示智能内核。

**构成要素：**
- 主图形：S 形酒杯曲线 + 顶部圆环
- 圆环内部：极细的电路/神经网络点线
- 整体呈现垂直对称的稳定感
- 最小使用尺寸：24×24px 时仍可辨识

**色彩应用：**
- 标准版：酒红 #722F37 单色
- 高级版：酒红→金色渐变（从杯底到杯口）
- 反白版：白色/奶白色 on 深色背景

**设计规范：**
- 安全区域：Logo 高度的 25% 作为四周留白
- 横版组合：图形 + "Somme AI" 文字（Cormorant Garamond, SemiBold）
- 纵版组合：图形居上 + 文字居下
- 禁止：拉伸、旋转、加描边、放在杂乱背景上

---

### 方向 B：**「品鉴之窗」 The Tasting Lens**

**概念描述：**

将酒杯的俯视图（完美圆形）与手机摄像头的光圈造型相结合。外圈是酒杯口的纤细线条，内部是类似光圈叶片的优雅分割，暗示"用手机观察/品鉴葡萄酒"这一核心体验。中心有一个微小的酒滴形光点。

**构成要素：**
- 外圆：纤细的酒杯口线条（1.5pt）
- 内部：5-6片弧形叶片，如光圈般优雅排列
- 中心：酒滴形光点
- 整体纯几何风格，现代感强

**色彩应用：**
- 标准版：酒红 #722F37
- 科技版：金色 #C9A96E（适用于深色背景）
- 渐变版：酒红外圈 → 金色中心

**设计规范：**
- 最佳尺寸：App Icon (1024×1024) 及各缩放版本
- 安全区域：图形直径的 20%
- 此方向特别适合作为 App Icon 和社交媒体头像

---

### 方向 C：**「对话之韵」 The Dialogue**

**概念描述：**

将经典的对话气泡与酒杯侧影巧妙融合。一个流线型的对话气泡，其底部过渡为酒杯杯柄和底座的曲线。气泡内可包含极简的省略号（···）或声波纹理，象征 AI 对话。

**构成要素：**
- 上部：圆润的对话气泡轮廓
- 下部：气泡底部自然延伸为酒杯杯柄+底座
- 气泡内部：三个小圆点（酒红色）或微波纹
- 整体形态似一个正在"说话"的酒杯

**色彩应用：**
- 标准版：酒红填充，内部圆点为金色
- 线描版：酒红描边，适用于浅色背景
- 动态版：气泡可配合 breathing animation，暗示 AI 思考中

**设计规范：**
- 此方向最能体现"AI 对话"核心体验
- 适合作为 App 内的品牌标识和加载动画
- 气泡与杯柄的过渡必须自然流畅，避免生硬拼接

## 4.6 插画方向

### 风格：**温暖极简主义 (Warm Minimalism)**

**特征：**
- 有限色板：仅使用品牌色（酒红、金色、奶白）+ 1-2个场景色
- 几何简化：人物/物体高度抽象，无面部细节
- 柔和线条：避免尖锐拐角，所有曲线都带有温暖的弧度
- 大面积留白：插画不应"填满"，呼吸感至关重要
- 纹理质感：轻微的纸张颗粒纹理（grain texture），增加手工感

### 场景插画方向

| 场景 | 描述 |
|------|------|
| **空状态** | 一只纤细的酒杯，旁边几滴酒红色圆点和一条金色弧线 |
| **扫描中** | 手机轮廓 + 酒瓶剪影 + 发散的光线 |
| **推荐完成** | 三个不同形状的酒杯排列，各带不同颜色的酒液 |
| **学习** | 翻开的书 + 酒杯 + 浮动的关键词气泡 |
| **酒窖空** | 空的酒架侧面线描，一个酒瓶等待放入 |
| **庆祝/成就** | 两只碰杯的酒杯 + 几颗金色星星 |

### 动态插画（Lottie Animations）

建议关键场景使用 Lottie 动画替代静态插画：
- 加载动画：摇杯（已实现 CSS 版本）
- 扫描中：光线扫过酒瓶
- 收藏成功：酒杯放入酒架
- 首次引导：侍酒师鞠躬欢迎

## 4.7 摄影风格指南

### 整体调性：**Moody Warmth — 温暖的戏剧感**

### 光线

- **主光：** 柔和的侧光/逆光，模拟烛光或黄昏自然光
- **色温：** 偏暖（3200K-4000K），避免冷白光
- **阴影：** 保留阴影层次，不过度提亮。阴影中带有酒红/棕色暖调
- **高光：** 玻璃上的高光点是关键美感元素，保留但不过曝

### 构图

- **浅景深：** F1.4-F2.8，主体清晰，背景虚化出柔美光斑
- **负空间：** 至少 40% 的画面留白/虚化，给文字叠加留出空间
- **视角：** 45° 俯拍（table setting）、平视（酒瓶肖像）、微距（酒液/气泡）
- **对角线构图：** 酒瓶/酒杯放在三分线交叉点

### 色彩后期

```
色调: 暗角 +15, 阴影偏暖 +10
饱和度: 红色 +5, 橙色 +10, 绿色 -15
明度: 整体微降 -5, 黑色 +10 (保留暗部细节)
锐化: 适度锐化酒标文字
纹理: 轻微 grain 纹理 +5-10
```

### 禁止事项 ❌

- 闪光灯直射（杀死氛围感）
- 过度 HDR（失去层次）
- 纯白背景产品图（太电商化）
- 人物正面证件照式合影
- 过度饱和的酒液颜色

### 推荐意象

| ✅ Do | ❌ Don't |
|-------|---------|
| 烛光下的酒杯 | 日光灯下的酒瓶 |
| 木质桌面上的自然摆放 | 白色背景棚拍 |
| 手持酒杯的自然姿态 | 刻意的握杯姿势 |
| 酒庄老墙前的酒瓶 | 超市货架上的酒瓶 |
| 斟酒瞬间的动态 | 摆好的静态产品图 |
| 带有食物的场景 | 孤零零的酒瓶 |

## 5.3 文案风格指南

### 中文文案

**核心原则：**
1. **口语化但不粗糙** — 用"你"不用"您"，但避免网络用语
2. **短句优先** — 每句不超过 20 字。如果需要长句，用逗号断开
3. **动词驱动** — "拍一下""试试看""选这支"
4. **情感词汇** — "优雅""迷人""令人愉悦"而非"好""不错""还行"
5. **避免术语墙** — 专业术语首次出现时附带通俗解释

**✅ 好的文案：**
```
"这是一支来自勃艮第的黑比诺。
 轻轻摇杯，你会闻到樱桃和紫罗兰的香气——
 像是春天花园里的下午茶。
 入口柔顺，单宁（就是让你口腔微微发涩的那种感觉）很细腻。
 配烤鸭或蘑菇烩饭都会很棒。"
```

**❌ 差的文案：**
```
"此款勃艮第黑比诺呈现典型的黑色浆果与花香特征，
 中等酒体，单宁细腻，酸度适中平衡度佳。
 适饮温度16-18℃，建议搭配禽类及菌菇类菜肴。"
```

### 英文文案

**核心原则：**
1. **Conversational, not casual** — Friendly but polished
2. **Active voice** — "We recommend" not "It is recommended"
3. **Sensory language** — Paint pictures with words
4. **Short paragraphs** — 2-3 sentences max per block
5. **Oxford comma** — Always

**✅ Good copy:**
```
"A beautiful Pinot Noir from Burgundy.
 Swirl your glass and you'll catch notes of cherry,
 violet, and just a hint of earthiness.
 Silky on the palate, with a finish that lingers.
 Try it with roasted duck — trust us."
```

**❌ Bad copy:**
```
"This Burgundy Pinot Noir exhibits typical varietal characteristics
 including red fruit aromatics and a medium-bodied palate structure
 with fine-grained tannins and balanced acidity."
```

### 专业术语处理

| 术语 | 首次出现 | 后续出现 |
|------|---------|---------|
| 单宁 Tannin | "单宁（让你口腔微涩的那种感觉）" | 直接使用"单宁" |
| 酒体 Body | "酒体（酒在嘴里的份量感）" | 直接使用"酒体" |
| Terroir 风土 | "风土——也就是葡萄生长的土壤、气候和环境" | "风土" |
| Decant 醒酒 | "醒酒（提前倒出来让酒'呼吸'一下）" | "醒酒" |

### 标点与格式规范

| 规则 | 中文 | English |
|------|------|---------|
| 句号 | 。（中文句号） | .（英文句号） |
| 引号 | 「」或"" | " " |
| 省略号 | …… | ... |
| 列表 | 用 · 或 — | Use — or • |
| 数字 | 阿拉伯数字（92分） | Arabic (92 points) |

## 7.3 品牌 Do's and Don'ts

### ✅ Do

- 始终保持酒红+金色+米白的核心配色
- 使用温暖、有质感的摄影风格
- 在专业内容中保持亲和的语气
- Logo 周围保持足够留白
- 中英文混排时注意字体搭配

### ❌ Don't

- 不使用明亮的霓虹色或荧光色
- 不使用卡通化的葡萄酒元素（除特定营销场景）
- 不在 Logo 上添加效果（阴影、描边、3D）
- 不使用冷色调（蓝、绿）作为主视觉
- 不将品牌调性降低为"便宜""折扣"导向
- 不在文案中过度使用网络流行语
