# v0.8 酒窖 2.0 — 设计文档

> 从列表 → 私人收藏画廊
> 目标：让酒窖从功能性列表变成有收藏感的视觉体验

## 一、核心变化总览

| 维度 | v0.5 现状 | v0.8 目标 |
|------|-----------|-----------|
| 布局 | 列表卡片（每项一行） | 画廊式网格（2列方格） |
| 分类 | 2 Tab（品过/想买） | 3 Tab（品过🍷 / 我的藏酒🏰 / 想买📖） |
| 酒标展示 | 小缩略图 64px | 大酒标方格，视觉冲击 |
| 排序 | 仅按时间倒序 | 多维排序（时间/评分/产区/品种） |
| 库存 | 无 | 藏酒可追踪瓶数 |
| 视图 | 仅列表 | 网格（画廊）↔ 列表 切换 |
| 无图占位 | 灰色背景 + emoji | 风格化占位（品牌色渐变） |

## 二、数据模型变更

### WineEntry 新增字段
```typescript
interface WineEntry {
  // 现有字段保留
  id: string;
  name: string;
  image?: string;
  type: "drinking" | "wishlist" | "collection"; // ← 新增 "collection"
  rating?: number;
  userNotes?: string;
  aiNotes?: string;
  date: string;
  region?: string;
  grape?: string;
  price?: string;
  tags?: WineTags;
  
  // v0.8 新增
  quantity?: number;    // 藏酒数量，默认 1（仅 collection 类型使用）
  vintage?: string;     // 年份（如 "2020"）
  producer?: string;    // 酒庄/生产商
}
```

### 排序选项
```typescript
type SortOption = "date" | "rating" | "region" | "grape" | "name";
```

## 三、UI 设计

### 3.1 Header 区域
- 保留现有 "✦ 我的酒窖 ✦" 标题
- 右上角：视图切换按钮（网格图标 ↔ 列表图标）
- 左上角：排序下拉（默认按时间）

### 3.2 Tab 栏 — 3 个 Tab
```
[ 🍷 品过的酒 ] [ 🏰 我的藏酒 ] [ 📖 想买清单 ]
```
- 滑动指示器宽度调整为 33%
- Tab 滑块动画保留

### 3.3 网格视图（默认）
- **2 列网格**，间距 12px
- 每个格子：
  - 正方形酒标图片区域（aspect-ratio: 1）
  - 图片圆角 16px
  - 底部叠加半透明渐变 → 酒名（白色文字）
  - 右上角评分 badge（与现有样式一致）
  - 无图时：品牌色渐变背景 + 🍷 大 emoji + 酒名
- **"我的藏酒" Tab 额外显示**：
  - 左下角瓶数 badge（如 "×3"）
  - 长按可调整数量

### 3.4 列表视图（切换可选）
- 基本保留现有列表卡片设计
- 增加产区/品种信息行
- "我的藏酒" 显示瓶数

### 3.5 排序浮层
- 点击排序按钮弹出底部 sheet
- 选项：最近添加 / 评分最高 / 按产区 / 按品种 / 按名称
- 选中项带 ✓ 标记

### 3.6 酒窖统计摘要（Tab 区域下方）
- 一行简短统计：`共 12 款 · 均分 78 · 5 个产区`
- 字号小，颜色淡，不喧宾夺主

### 3.7 空状态
- 网格模式下居中显示
- 每个 Tab 有不同的空状态文案
- "我的藏酒" 空状态：提示可以从 "品过的酒" 移入

## 四、交互设计

### 4.1 视图切换
- 点击切换按钮，网格 ↔ 列表
- 带 300ms 过渡动画
- 记住用户选择（localStorage）

### 4.2 排序
- 排序选项存储在 state，不持久化
- 默认按时间倒序

### 4.3 酒款操作
- **点击**：进入详情页（保留现有 WineDetailView）
- **左滑/长按**：操作菜单（删除 / 移动到其他分类）
- **"我的藏酒" 特有**：调整瓶数（+/- 按钮）

### 4.4 分类移动
- 从 "品过的酒" → "我的藏酒"：标记为 collection，quantity=1
- 从 "想买清单" → "品过的酒"：type 改为 drinking
- 操作通过长按菜单触发

## 七、视觉规范

### 颜色
- 使用现有 CSS 变量体系（--wine-deep, --wine-gold-warm, --wine-cream 等）
- 无图占位渐变：`linear-gradient(135deg, var(--wine-deep) 0%, var(--wine-burgundy, #5B2333) 100%)`
- 瓶数 badge：半透明黑底白字

### 字体
- 酒名：'Noto Serif SC', serif（保持品牌一致性）
- 统计数字：'Cormorant Garamond', serif

### 动画
- 网格加载：每个格子 stagger 入场（50ms 间隔）
- 视图切换：crossfade 300ms
- 排序切换：重排动画
