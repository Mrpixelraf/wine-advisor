# 🍷 Wine Advisor v0.6 — 场景化 UX 重设计

## 核心洞察
用户不是为了"跟AI聊天"而打开品酒顾问。他们有具体的场景需求。

## 四大用户场景

### 🍽️ 场景一：我在餐厅
**用户状态**: 坐在餐厅，看着菜单/酒单，需要快速决策
**核心需求**: 餐酒搭配、快速推荐
**时间压力**: 高（服务员在等）
**交互方式**: 
- 拍酒单 → AI识别并推荐
- 告诉AI点了什么菜 → 推荐搭配酒款
- 预算筛选

### 🛒 场景二：我在选购
**用户状态**: 在超市/酒庄/线上商城，面对大量选择
**核心需求**: 根据场景、口味、预算选酒
**时间压力**: 中
**交互方式**:
- 拍货架上的酒 → AI告诉你这瓶怎么样
- 选择场景（送礼/聚餐/自饮）→ 推荐
- 预算区间 → 精准推荐

### 📸 场景三：我有一瓶酒
**用户状态**: 手里有酒，想了解更多
**核心需求**: 识别酒款、品鉴指南、适饮建议
**时间压力**: 低
**交互方式**:
- 拍酒标 → AI识别 + 品鉴笔记
- 告诉AI年份/酒庄 → 详细信息
- 醒酒时间、适饮温度

### 🍷 场景四：我正在品酒
**用户状态**: 正在喝酒，想记录体验
**核心需求**: 引导品鉴、评分记录、学习
**时间压力**: 低（享受过程）
**交互方式**:
- AI引导看外观 → 闻香 → 品尝 → 记录
- 拍照 + 打分 + 写笔记
- 存入酒窖

### 场景进入后的引导流程

**餐厅模式**:
1. "您点了什么菜？"（文字/拍菜单）
2. "预算大概多少？"（快捷选项：¥100以下/¥100-300/¥300+）
3. → AI 推荐 2-3 款酒 + 理由

**选购模式**:
1. "什么场合？"（自饮/聚餐/送礼/约会）
2. "偏好？"（红/白/起泡/不确定）
3. "预算？"（滑块）
4. → AI 推荐 + 购买建议

**识酒模式**:
1. 📸 拍照或输入酒名
2. → AI 识别 + 品鉴卡片 + 评分 + 适饮建议
3. "要存入酒窖吗？"

**品酒模式**:
1. 📸 拍照或选择酒窖中的酒
2. AI 引导品鉴："先看看酒的颜色..."
3. 逐步引导：外观 → 香气 → 口感 → 余味
4. 打分 + 保存笔记
